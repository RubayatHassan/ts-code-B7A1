## Overview
This repository contains TypeScript practice problems and solutions covering core concepts such as functions, generics, classes, interfaces, utility types, and object-oriented programming.

## Topics Covered
- Basic Functions
- Type Annotations
- Generic Functions
- Interfaces
- Classes and Inheritance
- Utility Types (`Pick`, `Omit`)
- OOP Principles (Encapsulation, Abstraction, Inheritance, Polymorphism)
